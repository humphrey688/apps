☁️ 云同步（GitHub 免费方案） 多设备一致 · 照片不丢
🔌 未连接
为什么要 GitHub？ 完全免费、无限容量，照片会拆成单个文件上传，家里人和你的手机都能看到同一本手账。
第一次配置（3 分钟）：① 注册/登录 github.com → ② 新建一个私有仓库（New repository，名字随意如 fanfan）→ ③ 点头像 Settings → Developer settings → Personal access tokens → Tokens(classic) → Generate new token，勾选 repo 权限，生成后复制 → ④ 回到这里填上仓库名和 token，点「测试连接」→ ⑤ 点「立即同步」。
之后每天打开点一下 ☁️ 就同步好了；换新手机：装好本页 → 填同样设置 → 先「立即同步」把云端数据拉下来即可。Token 只存在你自己手机的浏览器里，请勿发给任何人。
